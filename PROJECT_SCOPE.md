# Implemented MVP Scope

## Implemented

- English-only React interface
- Django REST API
- SQLite database
- Login/logout token authentication
- Employee accounts with stored roles
- Admin-only employee account management
- Customer CRUD and calculated outstanding balance
- Supplier CRUD and calculated outstanding balance
- Product/category APIs
- Opening stock ledger entries
- Stock adjustments with insufficient-stock protection
- Sale creation inside a database transaction
- Stock reduction on confirmed sales
- Sale cancellation with stock reversal and payment safeguard
- Purchase creation inside a database transaction
- Stock increase on purchases
- Purchase cancellation safeguard and reversal
- Automatic document numbering
- Dynamic VAT, discounts and totals
- English PDF invoices
- Customer receipts and supplier payments
- PDF payment receipts
- Expense tracking
- Dashboard analytics
- Profit & Loss using sale-time cost snapshots
- Changeable company currency setting
- Company, VAT, invoice prefix, terms and bank settings
- Downloadable SQLite backup
- Responsive desktop/mobile-friendly web UI

## Deliberately not claimed as production-complete

- Fine-grained permission matrix for every button/API action
- Sales returns and purchase returns
- Credit notes
- Multi-warehouse transfers
- Serial-number traceability
- Barcode scanner workflow
- File/image attachments
- Email/WhatsApp sending
- Public cloud deployment
- Automatic cloud backups
- Safe browser-based database restore
- Full accounting general ledger / double-entry bookkeeping
- Tax authority compliance certification for a specific country

These can be added after the local MVP is tested and accepted.
